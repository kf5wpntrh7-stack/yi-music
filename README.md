# yi Music

yi 的手機 YouTube 歌單播放器，內建從 MB3 搬移的 5 個歌單，共 767 首歌曲。

## 功能

- 播放與搜尋歌單
- 新增、刪除、重新命名及排序歌單
- 移動歌曲與置換失效的 YouTube 來源
- 音量、隨機、循環、迷你播放器及黑屏模式
- JSON 備份與還原

## 資料保存

歌單變更保存在目前瀏覽器的 `localStorage`，不會在手機與電腦間自動同步。換裝置或清除瀏覽器資料前，請先在設定中下載備份，再於另一台裝置匯入。

## 手機播放限制

本播放器使用 YouTube 嵌入播放器。手機切換到其他 App、回到主畫面或關閉螢幕後，系統或 YouTube 可能暫停播放；網頁無法保證背景播放。
